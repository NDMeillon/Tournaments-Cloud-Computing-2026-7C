Tournament Services

Guía para armar un torneo desde el navegador. Cada botón llama a la API en este mismo servidor. El detalle técnico sigue en /swagger.

Estado: comprobando…

Los cuatro recursos

Equipo. Nombre único en todo el sistema.

Torneo. Formato: equipos por grupo, cantidad de grupos y tipo ROUND_ROBIN o NFL.

Grupo. Vive dentro de un torneo y recibe equipos hasta el máximo del formato.

Partido. Local y visita. Al anotar, el ganador sale del marcador.

Qué hace una petición

La ruta revisa el JSON. El delegado aplica la regla. El repositorio guarda en PostgreSQL.

El servidor inventa los ids (trn-, team-, grp-, match-). Esta página los guarda y los rellena en el paso siguiente.

Códigos que vas a ver

201 se creó. 200 se leyó o se actualizó. 204 se asignaron equipos, sin cuerpo.

400 el dato o el id están mal. 404 no existe. 422 la regla de negocio lo impide.

1Crear el torneo

Define el cupo. Con 4 equipos por grupo y 2 grupos, el torneo admite hasta 8 equipos repartidos en dos grupos.

2Crear los equipos

El nombre no se puede repetir. Si Mexico o Brasil ya existen, la API responde 400 y puedes elegirlos en la lista de la derecha.

3Crear el grupo

El grupo pertenece al torneo del paso 1. Un segundo grupo con el mismo nombre responde 422.

4Meter los equipos en el grupo

Hasta aquí los equipos existen, pero no juegan en el torneo. Este paso los asigna. La respuesta correcta es 204.

5Crear el partido

Los dos equipos tienen que estar en el grupo. Si eliges el mismo equipo dos veces, la API responde 422.

6Cargar el marcador

2 a 1 con Mexico de local deja el ganador en HOME. Un número negativo responde 400. Un empate deja el ganador vacío.
